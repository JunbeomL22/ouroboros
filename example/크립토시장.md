### 1.1 CEX vs DEX 비교

#### 시장 현황 (2025년)

| 구분 | CEX | DEX |
|------|-----|-----|
| 2025년 총 거래량 | $18.6조 (Spot) + $61.7조 (Derivatives) | Spot 점유율 최고 24% (2025년 6월) |
| 점유율 변화 | 여전히 가격 발견의 주요 장소 | 5년 전 1%에서 24%로 성장 |
| 유동성 | 상위 5개 거래소에 집중 | $155B+ TVL (전년 대비 40% 증가) |

> **출처:** [CoinBureau - Best Decentralized Exchanges 2026](https://coinbureau.com/analysis/best-decentralized-exchanges/)

#### 핵심 차이점

| 항목 | CEX (중앙화 거래소) | DEX (탈중앙화 거래소) |
|------|---------------------|----------------------|
| **자산 관리** | 거래소가 보관 (Custodial) | 사용자 직접 보관 (Non-custodial) |
| **KYC/신원인증** | 필수 (정부 ID, 주소 증명, 얼굴 인식) | 불필요 (익명 거래 가능) |
| **사용성** | 초보자 친화적, 고객지원 제공 | Web3 지갑 필요, 학습 곡선 존재 |
| **유동성** | 높음 (안정적 가격, 빠른 체결) | 상대적으로 낮음 (슬리피지 발생 가능) |
| **거래 수수료** | 0.1%~0.5% + 입출금 수수료 | 낮은 거래 수수료 + 가스비 별도 |
| **보안 리스크** | 해킹, 내부 위협, 규제 셧다운 | 스마트 컨트랙트 버그, 유동성 문제 |
| **자산 동결** | 거래소가 동결/정지 가능 | 불가능 (사용자 완전 통제) |

> **2025년 보안 현황**: 2025년 상반기에만 $21.7억이 암호화폐 서비스에서 도난당함

> **출처:** [MoonPay - CEX vs DEX Guide](https://www.moonpay.com/learn/cryptocurrency/cex-vs-dex), [BitPay - CEX vs DEX Complete Guide](https://www.bitpay.com/blog/cex-vs-dex)

### 1.3 API Rate Limit

#### Binance

| 항목 | 제한 |
|------|------|
| 연결 시도 | **300회 / 5분 / IP** |
| WebSocket 연결 비용 | 2 weight |
| 수신 메시지 | **10개/초** (초과 시 연결 해제) |
| 스트림 구독 | 최대 **1,024개/연결** |
| Ping/Pong | 3분마다 ping, 10분 내 pong 없으면 해제 |

- **위반 시**: 429 에러 → 2분~3일 IP 밴
- Weight 기반 시스템: 엔드포인트별 상이

> **출처:** [Binance - WebSocket Rate Limits](https://developers.binance.com/docs/binance-spot-api-docs/websocket-api/rate-limits), [Binance Academy - WebSocket Limits](https://academy.binance.com/en/articles/what-are-binance-websocket-limits)

#### OKX

| 항목 | 제한 |
|------|------|
| WebSocket 연결 | **3회/초 (IP 기준)** |
| 주문 API | REST와 WebSocket 간 rate limit **공유** |
| Private REST | User ID 기준 |
| Public REST | IP 기준 |

- 공개 채널: 공개 서비스 주소 사용
- 개인 채널: 개인 서비스 주소 사용
- Unified V5 API로 통합 관리

> **출처:** [OKX API Guide](https://my.okx.com/docs-v5/en/)

| 항목 | 제한 |

| WebSocket 연결 | **500개 / 5분** |
| 시장 데이터 연결 | 최대 **1,000개 / IP** |
| 배치 주문 | **1~10개 주문/요청** |

### 2.2 Perpetual Futures (무기한 선물)

#### 특성
- **결제**: 없음 (무기한 계약)
- **레버리지**: 최대 125x (거래소별 상이)
- **목적**: 투기, 헤지, 차익거래
- **2024년 거래량**: **$60조+**

#### Funding Rate 메커니즘

| 항목 | 내용 |
|------|------|
| **정산 주기** | **8시간** (00:00, 08:00, 16:00 UTC) |
| **기준 금리** | 0.01% / 8시간 (0.00125%/시간, **연 11.6% APR**) |
| **양수 Funding** | 선물가 > 현물가 → Long이 Short에 지불 |
| **음수 Funding** | 선물가 < 현물가 → Short이 Long에 지불 |
| **지급 조건** | 정산 시점 포지션 보유자만 |

> **핵심**: Funding Rate는 무기한 선물 가격을 현물 가격에 고정시키는 메커니즘. 정산 시점 전에 포지션 종료 시 Funding 수수료 미발생.

> **출처:** [Cube Exchange - Funding Rate Guide](https://www.cube.exchange/what-is/funding-rate), [Hyperliquid Docs - Funding](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/funding)

#### 청산 구조

```
포지션 → 마진 부족 → 청산 → Insurance Fund → ADL (Auto-Deleveraging)
```

| 단계 | 메커니즘 | 설명 |
|------|----------|------|
| 1 | **유지증거금 하회** | Mark Price 기준 청산 트리거 |
| 2 | **Insurance Fund** | 파산가격 초과 손실 1차 보전 |
| 3 | **ADL (Auto-Deleveraging)** | Insurance Fund 소진 시 발동 |

#### ADL (자동 디레버리징)

- **정의**: 청산 시 Insurance Fund로 커버 불가능한 손실을 **수익 포지션 강제 청산**으로 해소
- **우선순위**: 레버리지 수익률(Leveraged Return) 기준 랭킹 - **대형 수익 포지션일수록 ADL 대상 확률 높음**
- **2025년 10월**: $19B+ 청산 발생, 다수 거래소 동시 ADL 발동

**ADL 리스크 감소 방법:**
1. 레버리지 낮추기
2. 수익 포지션 일부 청산
3. **유지 마진 150% 알람 설정** 권장
4. **크로스 마진 모드** 활용

> **출처:** [Arxiv - Autodeleveraging](https://arxiv.org/html/2512.01112v2), [Bits About Money - Perpetual Futures](https://www.bitsaboutmoney.com/archive/perpetual-futures-explained/)

#### 거래소별 무기한 선물 사양

| 거래소 | 최대 레버리지 | 마진 유형 | 특징 |
|--------|--------------|-----------|------|
| Binance | **125x** | Cross/Isolated | USDT/COIN 마진, 최대 거래량 |
| OKX | **100x** | Cross/Isolated | 코인/스테이블코인 마진 |

### 3.4 두바이 (VARA)

#### 개요
- **VARA**: 2022년 Law No. (4)로 설립, **세계 최초 독립 가상자산 전담 규제기관**
- 관할: 두바이 전역 (DIFC 제외)
- **UAE 가상자산 채택률**: 인구 27.67% (세계 1인당 1위)

#### 라이선스 유형 및 자본 요건

| 유형 | 활동 | 최소 자본 |

| Advisory | 자문 | AED 100,000 (~$27,000) |
| Exchange | 거래소 운영 | **AED 1,500,000** (~$408,000) |
| Broker-Dealer | Fiat-VA/VA-VA 중개 | AED 100,000+ |
| Custody | 자산 보관 | 별도 규정 |
| **DeFi** | 스마트컨트랙트 감사 필수 | **AED 3,000,000** (~$817,000) |
| **DAO** | 2025년 Q4 예정 | **AED 2,000,000** (~$545,000) |

### 3.5 법인 설립 지역 선택 기준

#### 주요 관할권 비교

| 관할권 | 장점 | 단점 | 적합 대상 |
|--------|------|------|----------|
| **미국 (Wyoming)** | DAO LLC 선구자 (1,000+ 등록), 강력한 자산 보호 | 연방 규제 불확실성 | DAO, 자산 보호 필요 |
| **미국 (Texas)** | 2025년 기업법 개혁 (SB 29), 주요 거래소 이전 중 | 연방 규제 적용 | 대형 거래소 |
| **미국 (Delaware)** | 확립된 법적 프레임워크, 기관 투자 유치 | 엄격한 규제 | VC 투자 유치 |
| **EU (MiCA)** | **단일 패스포팅**, 명확한 규제 | 높은 준수 비용 | EU 27개국 진출 |
| **싱가포르** | 명확한 규제, 아시아 허브, 높은 신뢰도 | **극도로 제한적 발급** | 검증된 대형 기업 |
| **두바이** | **0% 세금**, 빠른 성장, 진보적 규제 | DeFi 높은 자본 요건 | 세금 최적화, 글로벌 확장 |
| **BVI** | EMI 온보딩 용이, 유연한 규제, 경제실체 규정 미적용 | 평판 리스크 | 스타트업, 토큰 발행 |

#### 선택 기준 체크리스트

**1. 사업 유형**
- CEX: 두바이, EU, 싱가포르 (고난이도)
- DEX/DeFi: 두바이 (고자본), BVI, 앤티가
- DAO: **Wyoming** (DUNA), 리히텐슈타인, 스위스

**2. 목표 시장**
- 미국: Delaware/Wyoming + 연방 라이선스
- EU: MiCA 라이선스 (네덜란드, 독일 추천)
- 아시아: 싱가포르 (고난이도), 홍콩
- 글로벌: **두바이** (UAE 기반 확장)

**3. 자본 규모**
- <$100K: BVI, 앤티가
- $100K~$500K: EU (자문), 두바이 (기본)
- >$1M: 싱가포르, 두바이 (거래소), EU (플랫폼)

**4. 세금 최적화**
- **0% 세금**: 두바이, BVI, 케이맨
- 저세율: 싱가포르 (17%), 리투아니아

**5. 뱅킹 접근성**
- 우수: EU, 싱가포르, 두바이
- 제한적: 역외 관할권
